# left_side_nav_layout 布局模板说明
## 模板概述
基于PyQt6实现的**左侧可折叠常驻导航 + 右侧弹性内容双栏布局**，依靠QSplitter实现左右区域拖拽调节宽度，侧边栏内部采用纵向分层设计：顶部标题折叠控制区、中部业务导航按钮区、弹性留白层、底部固定设置按钮，窗口支持最小尺寸限制，整体适配中小型桌面工具、轻量化管理系统，开箱即可二次开发。

## 目录结构
```
left_side_nav_layout/
├─ main.py          # 布局主代码文件
├─ assets/
│  └─ GriddyIconsSidebar.svg  # 侧边折叠/展开图标
└─ README.md        # 当前说明文档
```

## 核心特性
1. **双栏弹性分栏**：横向分割侧边导航栏、主内容区，支持手动拖拽调整宽度，侧边栏最大宽度锁定为220px，避免布局失衡；
2. **一键折叠展开**：顶部图标按钮收起侧边栏、右侧唤起展开按钮，最大化内容展示空间；
3. **侧边栏分层布局**
   - 顶部：标题栏+折叠控件；
   - 中部：可自由增减业务导航按钮，按钮居中排布、限定宽高区间；
   - 弹性空白：通过`addStretch()`自动填充剩余纵向空间，把设置按钮固定锚定在侧边栏底部；
   - 底部：独立高亮样式设置按钮，和普通导航做视觉区分；
4. **窗口适配保护**：默认窗口尺寸900×600，最小缩放限制800×520，防止小窗口控件挤压错乱；
5. **样式区分设计**：常规导航按钮浅色风格、底部设置按钮蓝色强调样式，交互hover/按下状态完整。

## 运行前置依赖
### 环境要求
Python 3.8+
### 安装依赖
```bash
pip install PyQt6
```

## 启动方式
1. 将图标文件放入`assets`目录；
2. 在当前目录执行命令：
```bash
python main.py
```

## 常用可调参数（main.py内全局常量）
| 参数名 | 默认值 | 作用 |
| ---- | ---- | ---- |
| side_expand_w | 220px | 侧边栏展开默认宽度 |
| side_max_w | 220px | 侧边栏可拖拽最大宽度 |
| menu_btn_mini_w | 160px | 导航按钮最小宽度 |
| menu_btn_max_w | 180px | 导航按钮最大宽度 |
| menu_btn_height | 38px | 导航按钮固定高度 |

## 适配软件场景
- 轻量桌面效率工具：格式转换器、文件批量处理工具、本地笔记阅读器；
- 小型业务管理客户端：门店进销存、本地考勤统计、简易数据采集程序；
- 素材管理、离线刷题、小型设备监控类桌面软件。

## 拓展修改指引
1. 增减导航菜单：修改`menu_names`列表内的文字即可批量新增/删除中部按钮；
2. 修改配色：分别调整普通按钮、底部设置按钮两段QSS样式代码；
3. 新增页面跳转逻辑：给中部导航、底部设置按钮绑定点击槽函数，对接右侧内容区切换逻辑；
4. 解锁最大窗口限制：取消注释`setMaximumSize`即可自定义窗口上限尺寸。

## 注意事项
运行前务必保证`assets`文件夹存在目标SVG图标，图标缺失会导致折叠按钮空白；可自行替换同名图标文件，无需改动代码路径。
