# top_nav_tabs_layout 布局模板说明
## 模板概述
基于PyQt6实现的**顶部常驻导航栏 + 多标签页内容区布局**，采用深色顶部导航 + 浅色内容区的配色对比。顶部导航按钮支持打开/切换模块页，内容区基于`QTabWidget`实现多标签页管理：可拖动排序、一键关闭、右上角"+"新建空白标签，适配多模块切换类桌面工具，开箱即可二次开发。

## 目录结构
```
top_nav_tabs_layout/
├─ main.py          # 布局主代码文件
├─ assets/
│  └─ GriddyIconsAdd.svg  # 新建标签"+"图标
└─ README.md        # 当前说明文档
```

## 核心特性
1. **顶部常驻导航栏**：深色背景，左侧标题 + 中部模块导航按钮（选中态蓝色高亮）+ 右侧新建标签按钮，横向不换行；
2. **多标签页内容区**：`QTabWidget`支持标签拖动排序（`setMovable`）、关闭按钮（`setTabsClosable`）、`setDocumentMode`现代文档式外观；
3. **导航联动**：点击顶部导航按钮打开/切换到对应模块页（同名标签存在则切换、不存在则新建），切换标签时自动同步高亮对应导航按钮，空白标签不高亮任何导航；
4. **防空白保护**：关闭最后一个标签后自动补建"首页"标签，避免内容区完全空白；
5. **占位页面样式**：每个标签页含模块标题 + 白色圆角占位卡片，背景色按标签数量循环取色，直观区分不同页面；
6. **窗口适配保护**：默认窗口尺寸900×600，最小缩放限制800×520，标签最小/最大宽度受限防止变形。

## 运行前置依赖
### 环境要求
Python 3.8+
### 安装依赖
```bash
pip install PyQt6
```

## 启动方式
1. 将图标文件放入`assets`目录；
2. 在当前目录执行命令：
```bash
python main.py
```

## 常用可调参数（main.py内全局常量）
| 参数名 | 默认值 | 作用 |
| ---- | ---- | ---- |
| nav_btn_height | 34px | 顶部导航按钮固定高度 |
| nav_btn_min_w | 88px | 导航按钮最小宽度 |
| add_btn_size | 32×32px | 新建标签按钮尺寸 |
| tab_min_w | 120px | 标签页最小宽度 |
| tab_max_w | 240px | 标签页最大宽度 |
| module_names | 4项 | 导航模块列表，增删即同步增删导航按钮 |
| page_colors | 5色 | 标签页占位背景色循环队列 |

## 适配软件场景
- 多模块切换类工具：浏览器式工具、文档工作台、配置管理面板；
- 需要并行打开多个页面的软件：多项目对比、多报表查看、批量编辑；
- 后台管理系统、开发者工具、数据查看器等顶部导航型桌面应用。

## 拓展修改指引
1. 增删导航模块：修改`module_names`列表即可同步更新顶部按钮与可打开的模块页；
2. 替换页面内容：在`_build_tab_page()`中把占位卡片替换为实际业务控件（表格、表单、图表等）；
3. 自定义配色：顶部导航深色背景、按钮选中蓝色、标签页浅色背景均为独立QSS代码段，按需调整；
4. 限制标签数量：可在`add_blank_tab()`/`open_module()`中增加`count()`上限判断；
5. 关联业务逻辑：给导航按钮绑定具体数据加载函数，替代默认的切换/新建标签行为。

## 注意事项
运行前务必保证`assets`文件夹存在目标SVG图标，图标缺失会导致"+"按钮空白；可自行替换同名图标文件，无需改动代码路径。
